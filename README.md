# E-Commerce & Kaspi SaaS Platform

Масштабируемая SaaS-платформа для автоматизации работы с поставщиками и маркетплейсом Kaspi.kz.

---

## Архитектура системы (Clean / Modular Monolith)

Система построена по принципам модульного монолита (DDD + Hexagonal / Ports & Adapters), что позволяет запускать MVP с минимальными накладными расходами на инфраструктуру, но гарантирует легкий распил на независимые микросервисы в будущем.

## Ключевые модули

### 1. Единый каталог (Master Catalog Core)
* **Канонический SKU (`MasterProduct`):** агрегирует несколько предложений разных поставщиков на один товар.
* **Каскадное сопоставление (Matching Engine):**
  1. EAN-13 / Штрихкод.
  2. Нормализованный артикул + бренд.
  3. Нечеткий поиск (Fuzzy / Trigram) с возможностью ручной модерации.

### 2. Модуль интеграции с поставщиками (Supplier Engine)
* Потоковый парсер CSV/XLSX (`app/modules/suppliers/parser.py`) — работает без переполнения оперативной памяти (O(1) memory), разбирает файлы любого размера батчами.
* Автоматическое обновление остатков и закупочных цен.
* Хранение нескольких офферов на один канонический товар.

### 3. Движок ценообразования (Pricing & Repricing Engine)
* **Выбор оптимального поставщика:** фильтрация только доступных остатков (`stock > 0`), выбор наименьшей цены, учет рейтинга/приоритета поставщика.
* **Конструктор наценок:**
  $$\text{Final Price} = (\text{Cost} \times (1 + \text{Markup}_{\%})) + \text{Markup}_{\text{fixed}}$$
* Контроль минимальной рентабельности (`min_margin_percent`) для предотвращения продаж в минус.

### 4. Модуль интеграции с Kaspi.kz
* **Kaspi XML Feed (`/api/v1/kaspi/feed/{slug}.xml`):** стриминг каталога в официальном формате Kaspi XML. Kaspi забирает актуальные цены и остатки по расписанию.
* **Kaspi Merchant API Client (`app/modules/integrations/kaspi/client.py`):** асинхронный клиент для выгрузки заказов, подтверждения и отслеживания статусов.
* **Юнит-экономика и маржинальность (`app/modules/orders/router.py`):** автоматический расчет чистой прибыли с учетом комиссии Kaspi и закупочной себестоимости выбранного поставщика.

## Быстрый старт

### Через Docker Compose:
```bash
docker-compose up -d
```
Сервисы будут доступны:
* Backend & Swagger API: `http://localhost:8000/docs`
* PostgreSQL: `localhost:5432`
* Redis: `localhost:6379`

### Локальный запуск:
```bash
# 1. Активировать venv
.\.venv\Scripts\activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить тесты архитектурных движков
python tests/test_core_engines.py

# 4. Запустить dev-сервер
uvicorn app.main:app --reload --port 8000
```
